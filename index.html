Why Smart Wrong Notebook

错题不是负担，
是下一步复习的入口。

从拍照上传到同类题练习，一条 AI 流水线替你完成整理、标注和出题。

错题自动吃透

上传题目，AI 自动识别内容并生成解析、知识点标签和同类练习题，弱项当场定位。

3 家 AI 自由切换

Gemini、OpenAI、Azure 网页内动态配置，兼容 OpenAI 格式的第三方服务（硅基流动、GLM、Kimi 等），无需重启。

按科目分本管理

数学、物理、英语等错题本独立管理，自动提取标签，自定义标签体系自由维护。

筛得准，印得全

按掌握状态、时间、标签、年级学期、试卷等级多维度筛选，一键导出打印或存 PDF，内容与图片缩放自定义。

智能练习补薄弱

基于错题生成相似练习题，把反复出错的环节变成定向巩固。

数据隔离，权限分级

多用户注册登录、数据安全隔离；管理员后台可启用/禁用违规用户，统计可视化掌握学习进度。

How it works

三分钟启动，五分钟开始分析。

01

启动服务

Docker 一条命令拉起，或本地源码运行；默认管理员 admin@localhost 登录。

$ docker compose up -d ✓ Started wrong-notebook on port 3000
02

配置 AI 提供商

首页右上角设置，选 Gemini / OpenAI / Azure 并填 Key，保存即刻生效，无需重启。

$ cat config/app-config.json { "provider": "gemini", "model": "gemini-2.5-flash" }
03

上传错题，开始复习

拍照或上传错题，AI 生成解析、知识点标签和同类练习题，随后筛选、导出、打印。

✓ 解析生成 · 3 条知识点标签 ✓ 生成 2 道同类练习题

The contract

默认行为说清楚，
不搞意外。

数据存哪、配置听谁的、权限怎么分——部署前先对齐这些默认行为。

默认行为说明
本地存储数据写入 SQLite 文件 dev.db，默认不出本机
配置优先网页设置存 config/app-config.json，优先级高于 .env
数据隔离多用户数据相互隔离，管理员可禁用/启用账号
HTTPS 要求截图导出功能依赖安全上下文，见 doc/HTTPS_SETUP.md

数据不出本机

默认 SQLite 本地文件存储，网页配置落本地文件；需要联网的只有 AI 请求本身。

需要远程访问时，按 HTTPS_SETUP.md 启用内置 HTTPS，或经 Docker 挂载 ./data 与 ./config 持久化。

多用户权限分级

注册登录即可使用，数据按用户隔离；管理员后台可禁用违规用户、删除违规账号，适合班级或家庭多成员共用一套部署。

Install

选你顺手的方式。

Docker、Docker Compose、本地源码，三种方式任选。

方式一 · Docker

Docker ≥ 20.10 · 快速测试

$ docker run -d --name wrong-notebook -e NEXTAUTH_SECRET="your_secret_key" -p 3000:3000 -v $(pwd)/data:/app/data -v $(pwd)/config:/app/config ghcr.io/wttwins/wrong-notebook

方式二 · Docker Compose

长期运行 · 推荐

$ curl -o docker-compose.yml https://raw.githubusercontent.com/wttwins/wrong-notebook/refs/heads/main/docker-compose.yml && docker compose up -d

方式三 · 本地源码

Node.js 18+ · 开发调试

$ git clone https://github.com/AmberjackQQ/wrong-notebook.git && cd wrong-notebook && npm install && cp .env.example .env && npx prisma migrate dev && npx prisma db seed && npm run dev
